Privacy Policy

Effective date: October 10, 2026

This Privacy Policy explains how BakenAI Desk (the "Tool"), operated by an individual creator in Japan under the name BakenAI (the "Operator"), handles information when you sign in with TikTok and upload videos.

1. Information the Tool receives from TikTok

  • Account identifiers and profile: your TikTok open ID, username, display name (nickname) and avatar URL. These are used only to show which account the video will be posted to.
  • Posting settings: the privacy options, interaction settings (comment, duet, stitch) and maximum video length that TikTok returns for your account. These are used only to show the right choices before posting.
  • Access tokens: the access token and refresh token TikTok issues after you allow the Tool. They are used only to upload the videos you approved and to check their upload status.
  • Upload results: the publish ID and status that TikTok returns for each upload.

The Tool does not request or read your followers, likes, comments, messages, watch history, contacts or location.

2. Videos and captions

The Tool sends only the video files and captions that you choose and approve. They are sent directly from your computer to TikTok.

3. Where information is stored

The Tool runs on the user's own computer. Tokens are stored in the macOS Keychain (or in a file readable only by the computer's user). Upload results are kept in a local file on the same computer. The Operator does not run a server for the Tool and does not collect your information on any server.

4. Sharing

Information is not sold, rented or shared with anyone, and is not used for advertising. It is sent only to TikTok, as needed to upload your videos.

5. Retention and deletion

  • Access tokens expire after 24 hours and refresh tokens after 365 days, as set by TikTok.
  • You can remove the Tool's access at any time in the TikTok app (Settings and privacy > Security and permissions > Apps and services permissions, or similar). After that, the stored tokens stop working.
  • The user can delete the stored tokens and local records at any time. If you used the Tool and want your information deleted, contact the Operator and it will be deleted within 30 days.

6. This website

This website does not use cookies, analytics or advertising trackers. It is hosted on GitHub Pages; GitHub may process technical information such as IP addresses to deliver the pages, under GitHub's own privacy statement.

7. Children

The Tool is not intended for anyone who is not allowed to use TikTok under TikTok's terms.

8. Changes

This policy may be updated. The date at the top of this page shows the latest version.

9. Contact

Email: komechanxo@gmail.com

プライバシーポリシー（日本語）

施行日：2026年10月10日

このプライバシーポリシーは、日本の個人制作者「バケンAI」（以下「運営者」）が運営する「BakenAI Desk」（以下「本ツール」）で、TikTokにログインして動画を送るときの情報の扱いを説明するものです。

1. TikTokから受け取る情報

  • アカウントの識別情報とプロフィール：TikTokの open ID、ユーザー名、表示名、アイコン画像のURL。投稿先のアカウントを表示するためだけに使います。
  • 投稿の設定：TikTokが返す、選べる公開範囲・コメント等の設定・動画の長さの上限。投稿前に正しい選択肢を表示するためだけに使います。
  • アクセストークン：許可のあとにTikTokが発行するアクセストークンとリフレッシュトークン。承認した動画を送ることと、その状態を確認することだけに使います。
  • 投稿の結果：TikTokが返す publish ID と状態。

フォロワー、いいね、コメント、メッセージ、視聴履歴、連絡先、位置情報は求めず、読みません。

2. 動画と説明文

利用者が選んで承認した動画と説明文だけを、利用者のパソコンから直接TikTokに送ります。

3. 保存場所

本ツールは利用者自身のパソコンで動きます。トークンは macOS のキーチェーン（またはそのパソコンの利用者だけが読めるファイル）に保存し、投稿の結果も同じパソコン内のファイルに残します。運営者は本ツール用のサーバーを持たず、サーバーで情報を集めることはありません。

4. 第三者への提供

情報を販売・貸与・共有することはなく、広告にも使いません。動画を送るのに必要な範囲でTikTokに送るだけです。

5. 保存期間と削除

  • アクセストークンは24時間、リフレッシュトークンは365日で、TikTokの仕様により期限が切れます。
  • TikTokアプリの設定（「設定とプライバシー」→「セキュリティと権限」→「アプリとサービスの権限」など）から、いつでも本ツールの許可を取り消せます。取り消すと保存したトークンは使えなくなります。
  • 保存したトークンと記録はいつでも削除できます。削除を希望する場合は運営者に連絡いただければ、30日以内に削除します。

6. このウェブサイト

このサイトは Cookie・アクセス解析・広告のトラッキングを使いません。GitHub Pages で公開しており、ページを届けるために GitHub が IP アドレスなどの技術的な情報を GitHub のプライバシーに関する方針にもとづいて扱うことがあります。

7. 子ども

TikTokの規約で利用が認められない方の利用は想定していません。

8. 変更

このポリシーは変更することがあります。最新版はこのページ上部の日付で示します。
